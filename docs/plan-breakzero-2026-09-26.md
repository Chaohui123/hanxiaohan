1. **自然流量枯竭（主因）**：全店自然搜索曝光 2-126 次/28 天。Ozon 搜索权重=销量+评价+广告信号+内容，我们 0 销量 0 评价，排名垫底。

## 二、调研结论：成熟 Ozon 跨境电商破零打法

1. **Ozon 搜索改革（2025）：标签（Tag）取代关键词**，每品最多 30 个标签，支持俄语+英语双语——**我们标签只 12-15 个没填满，是免费搜索流量的直接损失**（最大、最快的免费杠杆）。
2. **冷启动加权期 2-10 天**（新品流量倾斜窗口）——PZ30/188F 还在窗口内，老品已过。
3. **破零三件套**：商品卡优化（已有：内容 100 满分+内容型视频）+ 关键词/标签布局（标签补满）+ 首单激活（CPO/促销）。
4. **广告测款法**：每日 20 元小预算跑测款，跑出 5 个出单链接后拿销售额 5% 加大——别一开始就大烧（水泵包 CPC 941₽ 0 单就是反面教材）。
5. **CPO 按订单付费**是零风险破零工具（出单才扣费）——61N 已验证，其他品出单后解锁。
6. **评价是转化硬通货**：0 评价=信任零，首单评价激活权重。

3. **PZ30/188F 冷启动窗口利用**：两品还在 2-10 天加权期，标签补满+促销加权（已在弹性提升）+ 争取自然首单。

### P1 · 下周（破零专项+评价激活）

4. **集中火力破零 2-3 品**：61N 化油器包（已验证再扩）/ PZ30（新品期）/ 188F（新品期）——CPC 手动竞价 ≤15₽ 精准拉流量到能转化的品（不碰 AUTO）。

### P2 · 持续（权重积累+迭代）

## 四、关键认知（不再犯的错）

- **别一开始大烧 CPC**（水泵包 941₽ 0 单是教训）——先免费流量（标签/促销/内容）+小预算测款，跑出转化模型再放大。
- **0 评价是转化最大硬伤**——水泵包 1620 曝光 0 加购证明：没有评价，流量来了也不加购。破零比曝光更优先。
- **标签 30 个是免费流量第一杠杆**（Ozon 搜索改革后标签取代关键词）——我们一直没填满，这是最该先做的免费动作。
