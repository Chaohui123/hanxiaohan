# Ozon Agent 组织架构与现行流水线 SOP

> 2026-11-05 按 `AGENTS.md`、真实代码、用户批准的无货源测品规则和最新生产验收复核。早期“7 人并行即交付、先做素材后补证据、SQLite Checkpointer、自动广告测款”等初期设计已移除；后续章节中的日期记录必须服从本总则与最新状态快照。

## 一、角色与权限

| 角色 | 当前职责 | 验收与权限 |
|---|---|---|
| Kimi 主 Agent | 任务拆解、浏览器/生产 API、SOP 执行、知识维护、终审 | 独占 Ozon 商品/价格/库存写入及生产回读终审 |
| 调研/选品 | 需求、竞争、货源、变体、合规与素材证据 | 只读分析；缺证据不得放行 |
| 经济与定价 | 真实成本、汇率、佣金、物流、CPS、利润和广告上限 | Astra 攻坚，Carbon 可交叉复核；不直接改价 |
| 俄语文案 | 标题、描述、属性、标签和本地化 | Luna 可批量辅助，Kimi 核对参数与禁词后采用 |
| 视觉与视频 | 首图、图卡、视频封面、正常视频和配音 | 按现行模型路由制作；实物保真与连续动作不合格即弃用 |
| 代码与审计 | 日常工程、复杂跨文件审计、可靠性检查 | Gemini 4 Hydrogen 负责日常代码，Gemini 4 Carbon 负责复杂审计；不碰生产写入 |
| 独立质检 | 对照验收标准检查证据、内容和线上回读 | FAIL 不得按原证据继续，补证后针对变化重新复核 |
| 广告与复盘 | Direct 只读报表、经营数据、利润与转化分析 | 不自动扩品、加预算或启动 campaign |

这些是职责角色，不要求为每个任务重复调用全部模型。模型选择遵循 `AGENTS.md`，生产事实以 API/后台回读为准。

## 二、硬顺序与停止条件（2026-11-05 无货源测品修订）

```text
独立真实需求（Yandex 商品词搜索量或 Ozon 后台/前台需求数据）
  → 跨境竞争参考、供货、准确变体与关键参数
  → 真实单元经济（持续经营净利 10%–15% + 一周 CPS 预算）
  → 完整 8 图与双视频制作、独立复核
  → Kimi 执行上架测品、全字段生产回写与回读
  → 小批量出单后拿样、自拍更新替代与成本回写
  → 经营复盘、放量或停止、知识入库
```

- 真实需求是独立硬闸门；同类跨境卖家的动销、在售和评价只能参考，不能单独通过，也不能因其属于 Ozon 前台数据而绕过。
- 无货源直发不要求先买样或备货；初筛按同变体供应商标重和保守成本测算，累计 3 个有效付款订单后拿样、最迟不超过 5 单。供应商授权不设核验或停止项，自拍素材后续更新替代。
- 持续经营净利率 ≥10% 可测、≥15% 优先；按拟用仓库/线路计算。一周 CPS 预算、完整内容制作和已触发样品成本纳入测品台账，预算内亏损不得包装成持续盈利。
- 完整 8 图与双视频仍是上架标准，不能缩减或后置；选品与制作可并行，内容未齐不得上架。
- 每候选最多 2 家并行货源+1 家备选，只做一次集中复查；真实需求、准确身份、关键供货、经济或合规证据不足即结束本轮，不无限扩搜或新建同类定时任务。
- 后续取得新证据，必须重过经济及所有受影响闸门，不能沿用旧 PASS。
- 搜索、下载、方案、代码或报告只是过程；新品交付须有生产上架+回读，内容整改须有终审+线上更新+回读。

## 三、不可绕过的红线

1. **生产权限**：GPT、Gemini、Opus 与子代理不得直接操作 Ozon 商品、价格或库存；浏览器由主 Agent 直跑。
2. **全量替换**：Ozon import 前备份并对比线上属性、图片、视频和富内容；增量补属性当次回写建品脚本。
3. **兼容件文案**：禁 `оригинал`、`аналог` 和他人品牌词；OE 编号与适配关系只按证据表达。
4. **素材真实性**：高清实拍优先，不捏造形状、接口、数量、颜色或兼容性；无中文、无水印、无他人 logo，不原样照搬同行素材。
5. **广告与调价**：`PROMO_AUTO_DECISION=false`；Direct 仅按专项授权操作，付款人可结算不等于自动投放授权。
6. **数据真实性**：未知评分不能当 0，展示价不能冒充常规价，部分成功不能写成全批成功，未回读不能写成已上线。

## 五、技术、知识与复盘保障

- 生产主存储为 PostgreSQL，RAG 使用 pgvector；Redis 用于缓存与调度协调。不得再把 SQLite Checkpointer 等初期设想写成已上线能力。
- 业务决策先检索 RAG；新经验通过 `knowledgeGate + persistToPlaybook` 入库并验证召回，不能手写 SQL 绕过门禁。
- 媒体产物保存请求、素材与实际文件哈希，严格防旧文件串用；付费请求结果不明先对账，不自动重发。
- 每周复盘真实经营、竞品、Direct 报表、任务 last-run 与文档现行性；模型只分析，Kimi 最终核验并限定行动。
- 修改规则或实现时同步更新受影响文档，历史报告标日期，未部署/未验收项不得写成当前能力。

## 六、商品主图设计 SOP（2026-09-05 定稿 · 视觉设计强制）

> 依据：Ozon 官方规范（seller-edu）+ Amazon/大卖成熟方案调研 + 2026-09-05 全量主图 AI 诊断实证（11 个在售品主图全为"兼容性信息表"，18-42 分不合格）。

### 6.1 官方红线（违反→审核拒绝/黄灯降权/罚分）

1. **主图必须是真实商品实物照**：完整、彩色、清晰、对焦。图表/3D 模型/草图/占位图当主图直接违规（当前"兼容性信息表"主图正踩此条）。
2. 图上禁止：价格折扣、联系方式、外链、行动号召、配送/退货信息、促销词（лучший/№1/распродажа）。
3. 禁止：黑白照、模糊照、家居环境照（地毯/家具背景）、边框条纹、盗用他人照片（罚 200 分/2 个月）。
4. 水印四限制：不居中、覆盖≤50%、不含网址、与"品牌"属性一致（建议干脆不放）。
5. 技术参数：JPEG/JPG/PNG/HEIC/WEBP，单张 ≤10MB，200×200~4320×7680px；**2025+ 平台转向 3:4 竖版，新图统一 1200×1600（3:4）**。
6. 最多 30 张（1 主 + 29 附）；内容评分满分需 8 图 + 1 视频（影响搜索排名）。

### 6.2 主图执行口径（视觉设计必须达标）

| 项 | 标准 |
|---|---|
| 背景 | 纯白 RGB(255,255,255)（官方推荐+大卖全白底；我们类目非强制但按红线级执行） |
| 商品占比 | 75-85%（官方"占大部分画面"，行业执行值；AI 诊断阈值 <70% 打回） |
| 尺寸 | 1200×1600（3:4 竖版），四角背景色纯白 |
| 文字 | 零文字（或仅 1 条 ≤6 词俄语卖点，禁促销词） |
| 角度 | 正面/45° 实物，对焦清晰无阴影杂物 |

### 6.3 图集与双视频的并行结构（2026-10-26 修订）

先建立同一份“真实参数表 + 卖点证据表 + 分镜表”，图集与视频共用，不分别编造卖点。图集负责可放大的细节与完整参数，视频负责连续动作、使用顺序与购买前核对；不是把 8 张图卡轮播成视频。

**8 张图（一图一个信息任务）**：

1. **图1 主图**：白底真实商品，按 6.2 口径，首次上架前定稿。
2. **图2 全貌/包装清单**：多角度或零件平铺，数量与实物一致。
3. **图3 关键结构**：接口、螺纹、触点等高清特写，局部放大核对。
4. **图4 尺寸/适配核对**：使用真实测量值或有依据的同变体供应商标称值与 OE 对照；未拿样不得把标称值写成已实测，无依据不填估算值。
5. **图5 使用场景**：真实商品合成真实环境，不虚构车系、标志或安装效果。
6. **图6 核心收益**：材质/功能及使用前后差异，只写有证据的功能。
7. **图7 安装/使用顺序**：3–4 步简化图，警示必须核对的尺寸、极性或电压。
8. **图8 完整参数/包装/保障**：汇总购买决策信息，不编造质保或认证。

**两个独立视频上传项**：视频封面（12–15 秒，零音轨优先，静音可理解）与正常视频（20–26 秒，Edge 原速俄语+字幕）按 8.3 分轨制作。视频封面不是图集里的第 8 张静态图，不能用图卡轮播、无声正片或循环定格冒充。官方 CTR/转化提升数字若无本次实证不得写成承诺。

**无货源测品内容口径（2026-11-05）**：完整 8 图和双视频不因测品而缩减，仍须在正式上架前完成；选品与内容制作可并行，制作未完不能误判为选品失败。自拍素材在出单拿样后按更新替代路线替换首版图视频，不阻塞选品和首版制作，替换前后均须保证商品一致性并回读线上结果。

**兼容性信息三层归位**：主图零兼容性堆砌 → 图4 精简 OE/尺寸核对 → 完整兼容列表进属性字段与富内容。

### 6.4 制作流水线（依赖已就绪）

- 抠图：`@imgly/background-removal-node`（项目已装）或 rembg（isnet-general-use 模型，商用合规）；五金件硬边用默认模式即可
- 合成：sharp → 1200×1600 白底画布 → 按主体 bounding box 缩放到占比 75-85% 居中
- 场景图：实拍抠图 + AI 只动背景/光影（IC-Light 重打光）；**主图绝不 AI 生成产品本体**（防货不对板）
- 素材来源：1688 供应商白底实物图优先（选品红线已要求干净白底图 ≥3 张）

### 6.5 质检过闸（CI 式脚本，批量必过）

每张主图自动校验：①四角背景色 = RGB(255,255,255) ②主体占比 70-90% ③分辨率 ≥1000px ④无中文/水印/促销词。不合格自动打回，禁止上架。

### 6.6 图集标准工具链（2026-09-12 定稿 · 一次到位禁返工）

**禁止现场发明裁片/手估坐标**（2026-09 反复修图教训：手估裁片必出"多零件同框+裁切不完整"）。统一走：

1. **细节图**：`python temp/split-parts.py <全家福白底图> <输出目录>`——连通域自动分割（含二次清理去相邻残留），每零件白底 1200×1600 居中（target 0.70 长边，≤3.0x 放大防糊）。
2. **CI 质检闸**：`python scripts/image-qc.py <目录> --role main|detail|info`——①四角近白（info 豁免）②主体长边占比（main 70-95% / detail 45-95%）③长边≥1000px ④顶/底无深色横带。**退出码非 0 即打回，禁止上传**；落选小件（极小件 <45%）不进图集。
3. **信息图**：排版背景彩色属正常（info 档豁免四角白）；内嵌产品区一律用 split-parts 分割图，禁手估 crop。
4. **主图**：白底实物按 6.2 口径，`temp/build-main-sop.mjs <素材> <输出>` 合成后必过 main 档质检。
5. 水印处理：供应商顶/横带先用涂白预处理（浅色低饱和像素置白）再分割；中文水印横带用 whiten_band（差异检测版）——处理后必过 QC。

任何图未过 `image-qc.py` 不得进 pictures/import；改图后重新过闸再上传。

## 八、运营实战沉淀（2026-09-13 · 学习成果持续更新，交接必读）

### 8.1 关键词优化方法论（2026-09-13 学习+实战）
- **结构**：核心词（品名）+ 属性词（材质/尺寸/马力）+ 用途词（ремонт/замена/ремкомплект）+ 需求词（OE 件号/规格段）。名称≤100 字符，零品牌词；兼容件不得使用 `оригинал`、`аналог` 或他人品牌词，适配信息用具体 OE 件号与核对提示表达。
- **标签 23171**：按"核心/同义/马力/机型/用途/OE"扩到 12-15 个（不只 5 个！），全小写无空格词元（#ремкомплекткарбюратора），禁品牌词。
- **老品名称品牌词红线**：不只新建品，**全部在售老品也要排查名称/图文 Yamaha 等品牌词**（61N 8/3 上架名称带 Yamaha 至 9/13 才清除——67F 侵权停售同款风险，属定时炸弹，建品和巡检都查）。

### 8.3 双视频环节（2026-10-26 改版：视频封面与正常视频分轨）

**视频封面是替代主图的短视频，不是静态图片**：官方要求 MP4/MOV、8–30 秒、≤20MB、长边 1080–1920 像素、禁止边框。非 Fresh 类目用竖版 **3:4**，默认静音，必须不听声音也理解。普通视频官方时长为 3 秒–5 分钟；本项目按用户要求把两种成片内部统一为 8–30 秒、≤18,000,000 字节、1080×1440，不写成普通视频官方同规格。

**视频封面**：目标 12–15 秒，4 个连续镜头：是什么→关键结构→怎么使用→购买前核对。每屏一个信息任务、俄语短标签，以真实动作、接口特写和尺寸标注实现静音理解，不调用 TTS，优先零音轨。不能把图卡直接轮播，也不能把正片去音轨冒充封面。

**正常视频**：目标 20–26 秒，4–6 个连续镜头，按真实俄语原速 Edge 配音组织。先审逐字稿、生成配音，再按实际句长分配画面和字幕；超过 30 秒改文案，素材不足补真实镜头，禁止变速、定格和循环补时。

**源片与合成**：Omni 实测只接受 16:9/9:16 的 `response_format.aspect_ratio`，禁止传 3:4。源片按 9:16 生成，合成器中央安全裁切到 3:4；比例不一致的 clip 必须显式记录 `reframe.mode="center_crop"` 与 `safe_center:true`，无 pad、无拉伸。商品主体优先真实像素/真实动态素材，裁切后逐帧核对完整性。

**同源实拍与更新替代（2026-11-05 修订）**：主图视频字段存在不等于商品实拍。必须取得原片并逐帧核对同 SKU/变体/容量、颜色、结构、接口、数量与动作；错品、混款或工厂宣传片立即否决，真实连续运动也不能挽救错品。供应商授权不再设核验项、证明材料或停止条件。首版仍须完成完整 8 图与双视频；自拍素材在出单拿样后更新替代，不阻塞选品和首版制作。1688 官方以图搜款上传后须显式点击“搜索”，文件选择回执或 0/6 不是搜索结果。历史素材核验知识条目 `pb_main_video_content_gate_20261027`（ops）中的旧授权口径以本节为准。

**统一验收**：`temp/video-pro-pipeline/validate_media.py` 输出 `media-qc.json`，检查双片时长、实际字节、长边、编码、fps、音轨、全片解码、冻结、重复片段、场景突变和句尾。自动检测通过后仍须静音语义评审、真实商品一致性复核、正常视频俄语/字幕/原速试听和独立 QC。主 Agent 在后台分别上传两个上传项，选择器或接口失败先换已验证路径，不提前转交用户手动上传；只有真实官方功能未开放或需要敏感验证时才交还。

### 8.4 每次学习必更新
每日学习/实战踩坑/复核 FAIL/用户指正的方法论，**当天提交 Kimi 核验**：知识经 knowledge-gate 入库，SOP 由 Kimi 对照真实代码和回读后更新；每周清理先备份，历史实证标日期与“当时/历史”，禁止只留在对话里或让模型自行改写规则。

### 9.3 视频：9:16 连续源片 + 3:4 后期 + Edge 原速配音

- Omni 模型自 2026-11-06 升级为 `gemini-omni-1.2-flash`。官方支持 3–15 秒逐秒控制、最多6张参考图、多轮编辑与扩展、360p/720p/1080p/4K；720p 约 $0.07/秒。适配器新增 `duration` 与 `previous_interaction_id`，`duration=None` 时保留旧调用的5秒提示，显式才写 `response_format.duration="<N>s"`；首尾帧插值仍限3–10秒，实测时长偏差超过0.25秒即失败。`previous_interaction_id` 用于续编/编辑上一互动并进入缓存指纹；编辑已有视频时输出时长必须与源片一致，不能把15秒源片直接缩成3秒，需延长时按每次3–10秒、累计不超过30秒走扩展提示；`extend=True` 必须同时给 `previous_interaction_id`、正数 `previous_duration` 和显式 `duration`，请求写新增秒数，验收按源片+新增的总时长，不能把扩展片误判为仅新增片段。官方参考视频上传等能力未接入当前适配器，不得冒充已支持。适配器保留720p默认以兼容旧调用；新品按8.3显式 `aspect_ratio="9:16"`，小零件优先1080p源片，并在批量前核对实际输出与usage。最终双片总是1080×1440，不把源片档位当成任意输出尺寸承诺。
- `response_format.aspect_ratio` 只允许 `16:9`/`9:16`，禁止传 3:4。9:16→3:4 在后期等比放大、中央裁切，禁止 pad、拉伸；比例不同的 clip 必须显式 `reframe.mode="center_crop"` 和 `safe_center:true`，并逐帧核对主体、接口、数量和动作。
- 可用 `first_frame`/`last_frame` 做 Omni 原生连续插值；商品真实参考必须对应同一 SKU。**禁止 `tpad`、`stream_loop`、句尾定格、配音变速和反复慢放凑时**。素材不足就补真实镜头或缩短文案。
- 双视频编排 `python temp/video-pro-pipeline/run_one.py <path/to/video-plan.json>` 只接受 plan，`main.voice` 固定 Edge `rate="+0%"`，不提供 Gemini/GLM 环境切换。Gemini `gen_speech` 只作独立候选，不得未经新 A/B 评审接入正片。
- 配音用真实 WAV 帧数/采样率测每句时长，再做画面与字幕；超 30 秒改文案，禁止虚构逐词时间戳。声音克隆与 GLM TTS 禁用。Gemini 样音需 24kHz、mono、16-bit WAV，manifest 指纹与实际文件哈希全匹配才可复用。
- **当前 A/B 结论**：Argon 实际音频评审 Edge **73**、Gemini **55**，Edge 数字与单位更准确，故继续优先。候选评审必须实际提交音频，核对转写、发音、自然度和电商听感，不能凭文本或模型名假听。证据 `temp/omni-gen/test-out/tts/argon-ab-review.json`。
- **2026-10-26 双 Edge 音色盲评**：修订后的 6 句俄语真实生成 12 条音轨，`gemini-3.8-flash` 实际听审选择 A（Dmitry），A/B 为 5/4.5，未检出重音错误；新任务优先 Dmitry，保留 `rate="+0%"`。超时、空文本、无效符号串和 404 不算评审；标准 generateContent 对当前账户的旧 `gemini-2.5-flash` 已不可用，真实音频评审改走官方支持的 `gemini-3.8-flash` Interactions 文本输出。证据 `temp/media-sop-20261026/grillecover-dual/voice-ab/gemini38-interaction-review.json`。`make_vo_edge.py` 临时 MP3/VTT 必须传绝对路径，防止子进程 cwd 改变后找不到文件；不得吞掉真实 Edge 错误后复用旧音轨。

6. **持续经营利润**：净利率 ≥10% 可测、≥15% 优先，<10% 原则上不测；按拟用仓库/线路核价，不以未使用通道的最高运费否决，实际多仓同时开售则逐仓核算。采购、国内运费、包装、佣金、国际及尾程物流、退货准备、电子服务和支付等必要费用不得漏算，不能靠脱离市场的提价或漏项过闸。
7. **一周 CPS 测品账**：每 SKU 按 `5 × 预计成交价 × 实际CPS费率` 预留预算，后台先核实活动资格和实际费率，未开放或无资格不得伪称已开启。7 天或 5 个 CPS 订单先到即结束本轮并复盘，不自动续投。`测品总损益 = 全部订单持续经营利润 − 实际CPS费用 − 完整8图双视频制作成本 − 已触发样品成本`；预算内亏损可做为一次性测品投入，但不能写成 CPS 后盈利或长期可持续利润。只有高比例 CPS 才能出单且停后无自然转化时不继续长期补贴，本流程不联动打开 `PROMO_AUTO_DECISION`。
8. **完整内容标准不变**：完整 8 图、视频封面与正常视频仍是正式测品上架标准，不能缩减成 3 图或把双视频后置；选品与制作可并行，制作未完成是生产未完成而非选品 FAIL，但内容未齐不得上架。供应商授权不再设核验项、证明材料或停止条件；商品一致性、无中文/水印/logo、不原样照搬同行、连续真实动作、静音可理解及原速俄语配音等红线继续执行。
9. **停止与复核**：每候选最多 2 家并行货源＋1 家备选，做一次集中复查；真实需求、准确身份、关键供货、经济或合规证据不足才停止，不再因未拿样、无自拍或未取得供应商授权停止。需求/供货/经济复核通过后才付费制作，内容完成后做上架终审；FAIL 后不得按原证据继续，补证或关键条件变化须重过经济及受影响闸门，不无限扩搜或新建同类定时任务。
10. **桌面与视觉模型分工**：日常电脑任务分析、写作文案与视觉理解优先 **Gemini 4 Hydrogen**，统一走 `python scripts/gemini-hydrogen.py --prompt-file <文件> --output <JSON>`，图片通过重复 `--image` 参数传入；不再调用 `gpt-6.1-terra`。复杂跨文件代码审计与根因定位改用 **Gemini 4 Carbon**，统一走 `scripts/gemini-carbon-review.py`；它只读分析，不替代 Hydrogen 日常开发，也负责图卡/双视频分镜规划和选品、定价、单元经济的 Astra 交叉复核，检查成本漏项、汇率、佣金/CPS、竞品可比性及利润红线，不生成媒体或直接改价。Opus 因地区限制退出当前流程，不自动重试或换区。GPT/Gemini等辅助模型仅做非生产分析、生成及经授权的非生产电脑任务辅助；实际桌面操作由 Kimi 或既有工具执行，Ozon 商品、价格、库存的生产操作与基于生产回读的最终验收只能由 Kimi 主 Agent 执行。
11. **Direct 口径**：付款人身份本身不单独决定是否投放，不豁免适用的付款、账户、平台及合规核验。具体 campaign 必须另获用户授权，并核验利润/预算、广告法资料与 Ozon 集成；未全部通过不得创建或启动投放，不因付款人整改自动启动。`715426752` 已于 2026-10-27 经用户授权、全部闸门核验后启动；仅此 campaign，不得自动扩品或加预算。

13. **自动广告源文案与保存回读**：电商平台销售广告由店铺/Feed 信息自动生成，商品标题正常不代表广告正文合规；普通单词不得全大写，先对照实际广告预览定位来源，不能只查标题。修改源文案须单独获授权，只改对应字段，不能用新建 campaign、替换 Feed 或调整 CPA/预算绕过。保温罩实测从商品列表进入后台编辑器可同时更新 `description` 与 4191，不能把历史上 API 不写 `description` 的结论误用到后台表单；换行可能被序列化为 `<br/>`。保存后分别回读商品审核、两字段、标题、其他属性、媒体、价格字段、活动成员和库存；价格不变不代表活动成员未变。成员掉出时先查当前活动上限，不得为恢复原成员资格擅自降价。Direct 重生成、广告审核和实际展示必须另行回读，商品审核通过或 campaign 为活动不等于广告已恢复投放。
