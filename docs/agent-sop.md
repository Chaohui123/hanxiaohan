## 二、流水线（最终定稿）

```
选品专家 输出候选清单
  → 总控评审 GO/NO-GO（拦截：HD 干净图 <3 直接终止）
    ✅ GO → 三 Agent 安全并行【视觉设计 ∥ 俄语文案 ∥ 定价分析】
       核心：三并行全部完成且各自自检合格，才进下一环节（前置自检机制）
    ↓
  总控执行：类目匹配 + 属性填充 + API 建品 + 库存 + 富内容
    ↓
  质检专家 全量验收
    ✅ PASS → 广告冷启动
    ❌ FAIL → 精准整改工单（责任 Agent 专项整改）→ 复检（闭环）
    ↓
  广告运营 投放 + 数据复盘 → 结论同步选品专家 → 迭代下一轮
```

### 前置自检（新增）
所有专家 Agent 产出后**先自检达标**再提交总控/下游，大幅降低返工率。

### 整改 SOP（强制）
- 单次 FAIL 必须输出：问题位置、错误原因、整改标准、负责 Agent
- **最大重试 2 次**：2 次复检仍不过 → 总控判 NO-GO 终止该 SKU，避免无效消耗
- 整改记录归档，作 Agent 迭代与选品避雷数据

## 三、五条核心红线（全员强制）

1. **选品红线**：干净 HD 原图 <3 张，直接 NO-GO，禁止进入任何制作流程
2. **素材红线**：禁止裁剪/拉伸中文供应商模糊图；素材不足统一用"俄文卖点模板合成制图"
3. **质检闸门红线**：无质检 PASS 报告，禁止广告投放、禁止进流量池
4. **整改终止红线**：单 SKU 整改复检失败 ≥2 次，直接废弃
5. **数据闭环红线**：每轮广告复盘结论必须同步选品专家，实现越做越精准，禁止流水式无复盘上架

## 五、效率提升补充（2026-07-29 叠加）

### 选品前置三重筛查（选品专家必做，先行拦截）
- **资质认证**：需 EAC/3C/儿童资质的品直接 NO-GO
- **物流禁运/敏感品**：带电（内置电池）、液体、粉末、超大超重易碎——排查后决定
- **毛利率阈值**：测算毛利率 <40%（预留广告/折扣/退货）直接淘汰；同款大量低价内卷竞品避让

### Agent 产出自检（强制前置）
- 视觉/文案/定价三并行 Agent 产出后**先自检并输出自检报告**（JSON 模板），不合格内部重跑，再提交总控——压力不后移到质检
- 并行支持**局部重试**：单模块不合格只重跑该 Agent，其他成果保留

### 广告冷启动 7–14 天 SOP（广告运营执行）
- **0–7 天 数据采集期**：CPC 小额受控，不抢位；收集搜索词，CTR≥1.5% 合格（低则判素材/标题缺陷）；无效搜索词加否定词
- **7–14 天 潜力筛选**：稳定点击+加购 → 适度提预算；零互动 → 降预算暂停止损
- **0 评价新品不重仓**：先优惠券破零积累评价再加大预算；潜力款持续优化，低效款快速关停
- 复盘结论结构化回传选品专家（出单类目/卖点/价格带）

### 质检双审
- ①上架前预审（总控提交后正式发布前）②上架后线上复核（属性/图/价显示）
- 整改工单结构化：问题位置+违规类型+整改标准+责任 Agent，自动分发
- 反复问题沉淀进 `docs/pitfalls.md`（错误知识库），上游 Agent 前置规避

### 技术保障
- Agent IO 强制 JSON（禁自由文本），便于程序解析与任务流转
- BullMQ 限流控制并行 SKU 流水线数量（3–5 并发），防 LLM 算力瞬间打满
- SQLite Checkpointer 状态持久化，任务中断可恢复
- 统一素材资源库（原图/图集/文案/定价集中存储，多 Agent 共享）
- 类目→属性模板库：同类目 SKU 通用属性自动预填充，总控减负

### 三级缓存（同类复用，降本）
- L1 内存缓存：品类通用模板、固定公式
- L2 SQLite 持久缓存：已处理商品原图/文案包/定价测算
- 重复查询缓存：类目树、佣金比例、物流报价——同类商品二次上新直接复用历史产出

### 广告冷启动 SOP 基准（广告运营执行）
- 0–7 天：CPC 小额受控；**家居类目 CTR≥2% 合格**（其他类目 ≥1.5%），长期无点击判 Listing 缺陷
- 7–14 天：稳定点击+加购提预算，零互动降预算止损；0 评价不重仓（先优惠券破零）
- 复盘结构化（ROAS/CPC/有效搜索词/潜力评级）回传选品专家

### 分层测款（防资源浪费）
- 每轮 5–8 个候选 SKU 进完整流水线，不一次几十条
- 潜力品放大（同赛道扩品），滞销品确认后永久归档冻结

### 全局任务日志（SQLite，持续优化）
- 统计：各环节失败率分布、单 SKU 流水线平均耗时、选品通过率、整改平均轮次
- 按错误分布反向优化 Agent 提示词与前置校验规则，持续降返工率

## 六、商品主图设计 SOP（2026-09-05 定稿 · 视觉设计强制）

> 依据：Ozon 官方规范（seller-edu）+ Amazon/大卖成熟方案调研 + 2026-09-05 全量主图 AI 诊断实证（11 个在售品主图全为"兼容性信息表"，18-42 分不合格）。

### 6.1 官方红线（违反→审核拒绝/黄灯降权/罚分）

1. **主图必须是真实商品实物照**：完整、彩色、清晰、对焦。图表/3D 模型/草图/占位图当主图直接违规（当前"兼容性信息表"主图正踩此条）。
2. 图上禁止：价格折扣、联系方式、外链、行动号召、配送/退货信息、促销词（лучший/№1/распродажа）。
3. 禁止：黑白照、模糊照、家居环境照（地毯/家具背景）、边框条纹、盗用他人照片（罚 200 分/2 个月）。
4. 水印四限制：不居中、覆盖≤50%、不含网址、与"品牌"属性一致（建议干脆不放）。
5. 技术参数：JPEG/JPG/PNG/HEIC/WEBP，单张 ≤10MB，200×200~4320×7680px；**2025+ 平台转向 3:4 竖版，新图统一 1200×1600（3:4）**。
6. 最多 30 张（1 主 + 29 附）；内容评分满分需 8 图 + 1 视频（影响搜索排名）。

### 6.2 主图执行口径（视觉设计必须达标）

| 项 | 标准 |
|---|---|
| 背景 | 纯白 RGB(255,255,255)（官方推荐+大卖全白底；我们类目非强制但按红线级执行） |
| 商品占比 | 75-85%（官方"占大部分画面"，行业执行值；AI 诊断阈值 <70% 打回） |
| 尺寸 | 1200×1600（3:4 竖版），四角背景色纯白 |
| 文字 | 零文字（或仅 1 条 ≤6 词俄语卖点，禁促销词） |
| 角度 | 正面/45° 实物，对焦清晰无阴影杂物 |

### 6.3 图片排序模板（7+1 张，一图一卖点）

1. **图1 主图**：白底实物（按 6.2 口径）
2. **图2**：多角度/零件平铺（仍白底）
3. **图3**：**OE 号+适配机型精简对照**（把当前主图的兼容性表挪到这里——只列 Top 机型，字号≥48px）
4. **图4**：尺寸对比（手持/硬币等普世参照物）
5. **图5**：装机/使用场景图
6. **图6**：材质/质保卖点信息图（每张只 3-5 卖点、文字<50 字符）
7. **图7**：包装清单平铺
8. **视频封面**（8-30 秒无声循环）：可替代主图，官方统计 CTR +24%

**兼容性信息三层归位**：主图零兼容性文字 → 图3 精简 OE 对照 → 完整兼容列表进 Ozon 属性字段+富内容（富内容是放完整大表的合规位置，且点击率 +200% 级别）。

### 6.4 制作流水线（依赖已就绪）

- 抠图：`@imgly/background-removal-node`（项目已装）或 rembg（isnet-general-use 模型，商用合规）；五金件硬边用默认模式即可
- 合成：sharp → 1200×1600 白底画布 → 按主体 bounding box 缩放到占比 75-85% 居中
- 场景图：实拍抠图 + AI 只动背景/光影（IC-Light 重打光）；**主图绝不 AI 生成产品本体**（防货不对板）
- 素材来源：1688 供应商白底实物图优先（选品红线已要求干净白底图 ≥3 张）

### 6.5 质检过闸（CI 式脚本，批量必过）

每张主图自动校验：①四角背景色 = RGB(255,255,255) ②主体占比 70-90% ③分辨率 ≥1000px ④无中文/水印/促销词。不合格自动打回，禁止上架。

### 6.6 图集标准工具链（2026-09-12 定稿 · 一次到位禁返工）

**禁止现场发明裁片/手估坐标**（2026-09 反复修图教训：手估裁片必出"多零件同框+裁切不完整"）。统一走：

1. **细节图**：`python temp/split-parts.py <全家福白底图> <输出目录>`——连通域自动分割（含二次清理去相邻残留），每零件白底 1200×1600 居中（target 0.70 长边，≤3.0x 放大防糊）。
2. **CI 质检闸**：`python scripts/image-qc.py <目录> --role main|detail|info`——①四角近白（info 豁免）②主体长边占比（main 70-95% / detail 45-95%）③长边≥1000px ④顶/底无深色横带。**退出码非 0 即打回，禁止上传**；落选小件（极小件 <45%）不进图集。
3. **信息图**：排版背景彩色属正常（info 档豁免四角白）；内嵌产品区一律用 split-parts 分割图，禁手估 crop。
4. **主图**：白底实物按 6.2 口径，`temp/build-main-sop.mjs <素材> <输出>` 合成后必过 main 档质检。
5. 水印处理：供应商顶/横带先用涂白预处理（浅色低饱和像素置白）再分割；中文水印横带用 whiten_band（差异检测版）——处理后必过 QC。

任何图未过 `image-qc.py` 不得进 pictures/import；改图后重新过闸再上传。

## 八、运营实战沉淀（2026-09-13 · 学习成果持续更新，交接必读）

### 8.1 关键词优化方法论（2026-09-13 学习+实战）
- **结构**：核心词（品名）+ 属性词（材质/尺寸/马力）+ 用途词（ремонт/замена/ремкомплект）+ 需求词（анalog/OE 件号/马力段）。名称按"核心+马力段+аналог OE"组（≤100 字符，零品牌词）。
- **标签 23171**：按"核心/同义/马力/机型/用途/OE"扩到 12-15 个（不只 5 个！），全小写无空格词元（#ремкомплекткарбюратора），禁品牌词。
- **老品名称品牌词红线**：不只新建品，**全部在售老品也要排查名称/图文 Yamaha 等品牌词**（61N 8/3 上架名称带 Yamaha 至 9/13 才清除——67F 侵权停售同款风险，属定时炸弹，建品和巡检都查）。
- **主词验证**：Yandex Wordstat（前台 wordstat.yandex.ru 免凭证，或用 yandex-wordstat skill API 模式）——禁直译/凭感觉，一个词见"空白"先换 2-3 词形再搜。

### 8.2 内容评级满分口径（2026-09-13 实证）
- 构成：media 45（视频 cost 40 大分 + 8 图 cost 60）+ text 25（4191 100-500字符 cost 100 + 富内容）+ 其他属性 30（特征填充率）。
- **满分公式**：8 图 + 视频 + 4191(100-500字) + 富内容(11254) + 特征填满 = 100。查询：/v1/product/rating-by-sku。
- 缺视频是最大失分点（cost 40）——每个品都要轮播视频。

### 8.3 视频环节（2026-09-13 定稿）
- 流程：`temp/make-carousel-videos.py <sku>` 生成轮播 8-30s → **给用户 mp4 路径手动上传**（商品编辑页第3步「媒体」→ 添加视频 → 保存）。
- 自动化上传（upload-ozon-video.cjs）不可靠：①必须显式传 `--product <productId>`（默认写死旧品 ID 会传错商品）②分步编辑器"3 媒体"tab/下一步 CDP 点击不前进 ③/edit/media 直达跳帮助中心。手动兜底最稳。
