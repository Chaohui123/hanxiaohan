# 副厂损耗件上架链路 SOP（67F 验证版，2026-07-31）

> 由 67F 水泵叶轮（MAR-YAM-67F-01 / product_id 5753404525）全流程实证固化。
> 适用：冷门刚需小件（船配/汽配副厂损耗件）——**OE 编号+适配表驱动搜索流量**的品类。
> 总原则：**浏览器采集主 Agent 直跑（禁派子 Agent 碰浏览器），分析/制作派子 Agent 并行；每阶段有硬验收，不过即终止。**

## 阶段 0 · 方向锁定（用户战略）
- 冷门刚需汽配/船配小件；红海黑名单（通用卡扣/LED/雨刮/机滤/汽车通用火花塞/平衡杆胶套）；风险红线（刹车/转向/气囊/喷油嘴/氧传感器/高压传感器）
- 铁律：**售价 <800₽ 不做**（300₽ 跨境物流吞噬）；毛利 ≥40%；CEL Extra Small（≤135¥/≤500g/≤60cm）

## 阶段 1 · Ozon 竞品筛查（主 Agent 直跑 WebBridge）
- 工具：`temp/marine-scan.cjs` 模式——navigate 搜索页 → 滚动 → 页面 JS 批量提取（**不逐个开商品页**）；每词 ≤10 秒
- 采集：商品数量级 / 活跃卖家数 / 主流价格带 / 评论数（需求强度）/ OE·马力标注情况 / 重量尺寸线索
- **竞品链接必留档**：调研中锁定的头部竞品（价格带锚点/评论池大户/FBO 对手）完整商品链接逐条记录（上架后录入 `promo_competitor_links` 精准监控）
- 保留条件：**卖家 ≤15 + 有稳定评论 + 单件 ≤300g**
- 避坑：低马力段（<30hp）已被中国品牌矩阵击穿（146-600₽）；中大马力段（30hp+）原厂 OE 替代才有 1700-3800₽ 空间

## 阶段 2 · 1688 货源验证（主 Agent 直跑）
- 工具：`temp/src1688-scan.py`（**搜索词必须 GBK 编码**）；商品链接从 `offerId=` 参数重构
- 必查：拿货价/起批量/回头率、**OE 编号+适配车型/马力表可得性（汽配命门）**、重量尺寸、跨境专供标识、代发能力
- 素材：`scripts/download-1688-assets.cjs` 抓取 → `scripts/filter-images.py` 分辨率审计 → ReadMediaFile 逐张判干净度（白底/无中文/无水印，HD≥3 才立项）

## 阶段 3 · 交叉分析（3 子 Agent 并行，不碰浏览器）
- **定价**：**必须用 Ozon 实时价格复核**（快照会骗人——6H3 教训：调研 1390₽ 实时已塌 599-708₽）→ 单元经济（现价+8/28 佣金上调双列）→ GO/NO-GO
- **视觉**：素材逐张审计（可用/弃/重制）+ 大卖设计基准（头部主图=信息图，超车点=OE 适配表上图）+ 图集方案
- **文案**：标题实证结构「品名+马力段+аналог+OE 收尾」≤100 字符（同义词不堆砌）+ 关键词分层（核心大词进标题，长尾进属性）+ OE 交叉适配表（转化核心）

## 阶段 4 · 视觉制作（视觉 Agent，PIL）
- 3 张**独立版式**俄文信息图 750×1000（主图英雄式/适配表格式/尺寸工程式，同模板 ≤2 防判重）
- 视频：ffmpeg 剥音轨 → 卖点封面图（1:1）→ 合成为首帧 1.5s 拼接正片（Ozon 封面要视频格式）
- 红线：零中文零水印零裁剪；俄文用 arial/arialbd 西里尔字体

## 阶段 5 · 总控上架（主 Agent，API 直跑）
1. 类目：**竞品类目实证**（前台面包屑）+ 后台 type 匹配 + 字典值验证（如 22661=Крыльчатки охлаждения）
2. 传图：`temp/upload-frames.mjs` → 服务器 URL（M1：必须本地 JPG→服务器，禁 alicdn 直传）
3. 建品 `/v3/product/import`：CNY 报价、weight 克 int、尺寸 mm、vat "0"、offer_id ≤50 字符
4. 库存：等 3-5 分钟再设（O4）；`errors:[]` 即成功勿重试（O5）。**选仓按 CEL 官方双维档位表（8/20 用户供图，价格¥×重量）**：XS(≤500g 且 ≤135¥)=CEL陆运 `1020005021424150`；Budget(501g-30kg 且 ≤135¥)=CEL陆运2 `1020005021424290`（当前 DISABLED 需后台启用）；Small(≤2kg 且 135.01-635¥)=CEL陆运3 `1020005021424520`；Big(2-30kg 且 135.01-635¥)=CEL仓库3 `1020005021424710`；Premium Small(1-5kg 且 635.01-22525¥)=CLE陆运5 `1020005027799150`（打窝船仓，用户建仓）；Premium Big(≥5kg 且 635-22525¥)=CEL陆运4 `1020005027716120`。**调价跨档自动迁仓已上线**（71cfcf4 起，按此双维表，目标仓=rfbs 总库存、其余仓清零，失败不阻断）；手动兜底工具 `temp/move-stocks-xs.cjs`；FBP 仓（Ural/GUOO）库存不可 API 手动更新
5. **描述走 attribute 4191**（O9：v3 import 会静默丢 item.description）；**文案禁"оригинал\*"字眼**（O10：FB_ORIGINAL 拦截，用 штатный/аналог）
6. 补尺寸属性（7956 Длина/8416 Ширина cm 等）提内容评级
7. **生成 OZN 条形码**（8/24 合同新规：转交货物时卡片未指明所贴条形码→Ozon 可拒付赔偿；9 在售品 8/19 已补齐 `temp/gen-barcodes.cjs`：`POST /v1/barcode/generate {product_ids}`；**发货实物必须贴对应 OZN 码**，码=OZN+sku）
7. 富内容：CDN 图址就绪后组装 → `scripts/validate-rich-json.cjs` 预检 → 写 11254
8. **录货源成本+竞品链接（硬性，上架即录）**：①`sku_1688_mapping`：`ozon_offer_id` + `ozon_sku` + `source_1688_url` + `purchase_price_cny`（区间取中位）+ `weight_kg`——缺失则决策引擎利润率评分不成立、出单后采购匹配断链。②`promo_competitor_links`：阶段 1 留档的竞品链接逐条录入（offer_id + competitor_url + competitor_name）——缺失则竞品监控只能靠商品名模糊搜索（不准）。历史 8 SKU 已于 2026-08-13 补录。
9. **Ozon 后台添加官方竞品链接（硬性，上架 T+0 完成）**：把阶段 1 留档的竞品链接提交到 Ozon 官方"价格指数"竞品库（官方计算价格指数、发"就是这个价"徽章+搜索提升；72h 生效）。操作：价格页该商品行"竞争对手的价格"列"未指定→添加"，或价格管理页 `/app/prices/manager/{product_id}/prices`"Ozon上的竞争对手价格→添加链接"；**批量用 `temp/add-competitor-links.py <offerId>`（价格页）/ `temp/add-links-here.py <url...>`（弹窗就地）**，提交后点"发送以进行审核"。注意：已下架商品无添加入口（恢复后补）；Ozon 自动匹配的跨平台竞品（如 wildberries）不代表我方精准竞品，必须手动补 Ozon 平台内同款。历史 7 SKU 已于 2026-08-14 提交 31 条。
